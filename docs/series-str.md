# Str 系列 — 語と書き換え

`Core/StrAlgebra/StrAlg.m` を中核とし、`StrEndV`, `StrUqsl2`, `StrQUEAlg`,
`StrAnAlg`, `StrCnAlg`, `StrWeylXQ`, `StrWeylAlg`, `StrCnmodalg` などが派生する。

## 思想

**代数の定義をそのまま入力する。**

生成元を自然数ラベルに、単項式をラベルの配列に、多項式をその線形結合に対応させる。
関係式は「0 に等しい `StrAlg` オブジェクトの配列」として持つ。積は語の連結で定義し、
その後**関係式を検索して適用しながら、語が辞書式昇順になるようバブルソート的に
書き換える**ことで正規形を得る。

$U(\mathfrak{sl}_2)$ で $E{:}1, F{:}2, H{:}3$ と番号付けたとき、`FE` は配列 `[2 1]`
なので `[1 2]` になるよう $FE = EF - H$ を適用する、というのが計算の全て。
アルゴリズムの詳細は `Execution/Docs/W241223QiitaMATLABAdvent.md` にある。

## この系列でしかできないこと

**関係式そのものを検証対象にできる。** これが `Str` の最大の存在意義。

`StrAlg.checkRepresentation`（`Core/StrAlgebra/StrAlg.m:233-271`）は、定義関係式を
表現 `rep` で送って 0 になるかを確認する。関係式を第一級のデータとして持っている
系列でしか成立しない操作であり、`Pol` にも `Vec` にもこれに相当するものはない。

新しい表現を提案したとき、それが本当に表現になっているかを機械的に確かめられる
のはここだけ。

## 何が得られるか

- **定義の忠実さ。** Drinfeld–Jimbo 表示のような「生成元と関係式」の記述を、
  紙とほぼ同じ形で書ける。Serre 関係式のような複雑な関係式も、そのまま関係式の
  配列に入れるだけで済む。
- **無限次元でよい。** 包絡代数や量子群を切り詰めずに扱える。
- **テンソル積と Hopf 構造が自然に乗る。** `pw` が「テンソル積因子の横方向の配列」
  になっているので、余積・Hopf pairing・$n$ 重余積が同じデータ構造の上で動く。
- **型の外側から関係式を差し替えられる。** `CartanData` から Cartan 行列を作り、
  そこから関係式を自動生成する（`StrQUEAlg`）という構成が取れる。Dynkin 型ごとに
  クラスを書き分ける必要がない。

## 何を払うか

- **書き換えの反復コスト。** 積のたびに正規化が走る。項数は容易に増える
  （$F^3H^2E^2$ が 11 項になる）。
- **停止性の保証がない。** 反復上限が `replace(obj,30)` とハードコードされている
  （`StrAlg.m:373`）。上限に達しても警告は出ない。新しい関係式系を入れたときは、
  正規化が本当に収束しているかを疑うこと。Gröbner–Shirshov 的な合流性の検査は
  実装されていない。
- **生成元の番号付けが性能を決める。** 辞書式順序が正規形を定義するので、番号の
  付け方によって書き換え回数が変わる。
- **指数を記号にできない。** $x^{\alpha}$ のような記号指数は語では表現できない。
  これが必要なら `Pol` へ行く。

## 落とし穴

- `StrAlg` の `rank` は**テンソル階数**を意味する（Dependent プロパティ）。
  Lie 環の rank ではない。派生クラスで Lie の rank を同名プロパティにすると
  衝突してクラスがロードできなくなる。
- `pw` はセル配列。単項式の長さが揃わないジャグ配列だからで、これは避けられない。
  ベクトル化しにくいのはこの表現の必然的な代償。
- ゼロ判定が `simplify` 依存である点は [DESIGN.md](DESIGN.md) の注意を参照。

## StrEndV — 作用素を語として持つ特殊化

`Core/StrAlgebra/StrEndV.m` は `StrAlg` を継承し、生成元を「作用素の種類」
（`id`, `d`, `x`, `xd`, `dd`, `th`, `qth`）にしたもの。

**作用素の代数は `Pol` にも `Vec` にも載らない。** 作用素の間に成り立つ関係
（$D_qx - qxD_q$ が何になるか、$q^\theta$ と $x$ がどう交換するか）は生成元と関係式で
与えられるものであり、単項式の正規形が先験的にあるわけではないので `Pol` には
載らない。次元も無限なので `Vec` にも載らない。だから作用素は `Str` で持つ。

一方で、各作用素は `Pol` の指数ベクトルへの作用として実装されている。$q$ 微分
$D_q$ は「係数に $[p_i]_q$ を掛けて $p_i$ を 1 下げる」、$q^{c\theta_i}$ は
「係数に $q^{c p_i}$ を掛ける」という具合。つまり `StrEndV` は、代数としては `Str`、
作用先としては `Pol` を向いている二面性を持つ。

**作用素の実際の作用が定義されている唯一の場所**なので、$q$ 微分作用素表現を
扱うときは必ずここを見ること。新しい種類の作用素が要るときも、ここに一つ
追加するのが正しい。
